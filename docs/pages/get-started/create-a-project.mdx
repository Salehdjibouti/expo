5. Admin gives out the code manually through web panel (not in this app).
6. Simple navigation bar for Home, Homework, Attendance, and Messages.

Please include:
- Flutter main.dart
- All necessary Firebase setup files
- Folder structure
- Sample Firestore rules (read-only access for logged-in parents)
